# World news of 19 November 2026 — in one image

Entry for the make.fun bounty
[news-image-20261119](https://make.fun/bounty/news-image-20261119).

`entry.png` is a one-page front page summing up Thursday 19 November 2026:
Hakeem Jeffries nominated for US House Speaker, the Trump–Xi–Putin
trilateral in Shenzhen, US–Iran strikes, Cyclone Akvan, the GTA VI launch,
and more. `draw.py` (Python 3 + Pillow, standard fonts) redraws it from the
story list; `main.ts` copies `entry.png` to `/output/entry.png`, as the
bounty requires.
